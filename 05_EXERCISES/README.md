# Exercícios

Listas abertas criadas pela Skill `practice-set` ficam organizadas por tópico:

`05_EXERCISES/<Tópico>/<YYYY-MM-DD - lista de exercícios.md>`

Cada lista preserva os enunciados, as tentativas do usuário, o feedback, os acertos, os erros e os gaps encontrados. Listas anteriores não devem ser apagadas ou sobrescritas; novas versões são criadas como arquivos separados.
