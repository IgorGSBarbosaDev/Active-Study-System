# Active Study System

Vault de estudos baseado em aprendizagem ativa, recuperação de conhecimento, feedback de erros e revisão espaçada.

## Estrutura

- `01_TOPICS` — conhecimento estudado.
- `02_REVIEWS` — revisões.
- `03_PROJECTS` — aplicações práticas.
- `04_RESOURCES` — fontes externas.
- `99_SYSTEM` — método, estratégia e templates.
- `.pi` — automação do Pi Harness.
