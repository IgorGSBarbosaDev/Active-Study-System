# Criar lista

Use três exercícios por padrão. Amplie para até cinco quando o usuário pedir uma lista completa, informar tempo suficiente ou quando três itens não cobrirem o objetivo delimitado. Quantidades maiores exigem pedido explícito.

- Respeite quantidade e linguagem solicitadas.
- Use somente questões abertas com entrega observável: explicação, rastreamento, implementação, correção, testes, complexidade, diagnóstico, comparação ou decisão justificada.
- Varie dificuldade e tipo apenas quando isso representar o objetivo; não cumpra uma checklist artificial.
- Peça justificativa para decisões, previsões e escolhas técnicas.
- Use Java quando o contexto for backend/Java e não houver linguagem diferente pedida.
- Não inclua solução, gabarito, dicas reveladoras ou feedback no enunciado.
- Use gaps e erros anteriores sem repetir enunciados nem tratar resposta antiga como evidência atual.

Apresente a lista completa quando couber. Se for extensa por pedido do usuário, aplique em lotes sem mudar o arquivo persistido.
